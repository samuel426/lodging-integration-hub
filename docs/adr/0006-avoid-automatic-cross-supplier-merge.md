# ADR 0006: 공급사 간 자동 상품 병합 제외

- 상태: Accepted
- 결정일: 2026-09-03

## 배경

여러 Supplier가 같은 이름의 숙소나 유사한 객실을 제공할 수 있지만 공통 식별자가 없습니다. 이름과 주소만으로 자동 병합하면 실제로 다른 상품을 하나로 묶을 위험이 있습니다.

## 결정

Supplier가 다르면 기본적으로 별도의 내부 숙소와 객실 타입으로 저장하고 검색 결과에도 출처를 표시합니다. 자동 matching과 대표 상품 선택은 현재 범위에서 제외합니다.

## 결과

- 잘못된 병합으로 인한 상품 조건 오염을 피합니다.
- 같은 물리적 숙소가 검색 결과에 여러 번 나타날 수 있습니다.
- 향후 병합에는 별도 matching 규칙, 신뢰도, 수동 검증과 provenance가 필요합니다.

## 검토한 대안

- 이름 기반 병합: 표기 차이에 취약하고 동명이 숙소를 구분할 수 없습니다.
- 이름과 주소 기반 병합: 정확도는 높아지지만 공통 주소 정규화와 검증 절차가 없습니다.
