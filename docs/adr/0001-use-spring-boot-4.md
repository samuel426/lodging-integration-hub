# ADR 0001: Spring Boot 4.0.8 사용

- 상태: Accepted
- 결정일: 2026-09-03

## 배경

Java 21 기반의 신규 백엔드에서 사용할 Spring Boot 계열을 정해야 합니다. 익숙한 3.5 계열과 최신 4.1 계열, 패치가 누적된 4.0 계열을 비교했습니다.

## 결정

Spring Boot 4.0.8을 사용합니다. [Spring 공식 안내](https://spring.io/blog/2026/06/25/spring-boot-3-5-16-available-now)에 따라 3.5.16은 3.5 계열의 마지막 OSS 릴리스이므로 신규 기반에서 제외했습니다. 4.1은 출시 직후보다 생태계 호환성이 확인된 뒤 검토합니다.

## 결과

- 지원 중인 4.x 기반으로 구현합니다.
- Spring Framework 7과 Jakarta 생태계의 변경 사항을 적용합니다.
- 라이브러리 추가 전 Boot 4 호환성을 확인합니다.
- Boot dependency management가 제공하는 버전을 우선 사용합니다.

## 검토한 대안

- 3.5.16: 익숙하지만 OSS 지원이 종료되는 계열입니다.
- 4.1.1: 더 최신이지만 현재 범위에서 필요한 기능 이점보다 초기 적응 비용이 큽니다.
